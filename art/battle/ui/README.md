# Battle UI Icons

These transparent action icons were copied from the predecessor
Pokémon Fracture and Revolt prototype's `art/icons/` directory at the
project owner's direction:

- `icons/sword_icon.png` — Fight
- `icons/bag_icon.png` — Bag
- `icons/pokeball_icon.png` — Pokémon and the player HP card
- `icons/run_icon.png` — Run

The Godot scenes reference the final PNGs directly so imports and Web exports
include them deterministically. The predecessor's editable GIMP workspaces and
intermediate generation buffers are intentionally not duplicated here.
